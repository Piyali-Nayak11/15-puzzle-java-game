# 15-puzzle-java-game
-**Goal**: Arrange the numbered tiles in ascending order from 1 to 15 (top-left to bottom-right), leaving the empty slot in the bottom-right corner.  
-**Controls**: Click any tile directly next to the dark empty space to slide it into place.  
-**Visual Feedback: **Tiles automatically turn green when placed in their correct final spot.
